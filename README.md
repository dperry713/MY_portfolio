# Dustin Perry — Software Engineering & Cybersecurity Portfolio

Personal portfolio and resume for Dustin Perry, focused on software engineering, cybersecurity, backend development, and secure AI infrastructure.

## Project files

- [portfolio.html](./portfolio.html) — portfolio and resume content
- [styles.css](./styles.css) — responsive visual design and print stylesheet

## Features

- Responsive dark interface with cyan and purple accents
- Accessible navigation, keyboard focus states, and reduced-motion support
- Professional profile, technical skills, experience, projects, and education
- Print-friendly resume layout using the browser print dialog to save as PDF
- Mobile navigation and lightweight scroll-reveal interactions
- No build step or package installation required

## Run locally

Open `portfolio.html` directly in a browser, or run a local static server:

    python -m http.server 8080

Then open http://localhost:8080/portfolio.html.
